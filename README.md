# Sales Analytics Dashboard

## Project Overview

Interactive Sales Analytics Dashboard built using Power BI to analyze sales performance and generate business insights using visual analytics.

## Dashboard Features

- Total Sales
- Total Profit
- Total Orders
- Profit Margin
- Sales by Region
- Monthly Sales Trend
- Sales by Category
- Top 10 Customers by Sales
- Sales by State
- Interactive Filters (Year, Region, Category, Segment, Ship Mode)
- Key Business Insights Section

## Key Insights

- West region has the highest sales contribution
- Top customer generated highest revenue
- Technology category contributes major sales

## Tools & Technologies

- Power BI
- Data Visualization
- Dashboard Design
- Data Analysis

## Files Included

- Dashboard Screenshot (.png)
- Dashboard Report (.pdf)
- Power BI Dashboard File (.pbix)

## Outcome

This dashboard helps users monitor sales performance, identify trends, compare regions, and support business decision-making through interactive visual reports.
